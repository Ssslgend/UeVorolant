## 🔥 必须会的知识（今天就学）

### 1. UE 编辑器基础操作（30分钟）

#### 1.1 视角控制
```
鼠标右键 + 移动鼠标    → 环顾四周（旋转视角）
W A S D               → 前后左右移动
鼠标滚轮              → 前进/后退
按住 Shift            → 加速移动
F                     → 聚焦选中的物体
```

#### 1.2 选择和变换
```
左键点击              → 选中物体
W                    → 移动模式（显示箭头）
E                    → 旋转模式（显示圆圈）
R                    → 缩放模式（显示方块）
Delete               → 删除选中物体
Ctrl+Z               → 撤销
Ctrl+Y               → 重做
```

#### 1.3 保存
```
Ctrl+S               → 保存当前关卡
Ctrl+Shift+S         → 保存所有修改的资产
```

#### 速成方法
1. 打开编辑器
2. 随便创建一个关卡（File → New Level → Basic）
3. 从 Place Actors 拖几个物体进去
4. 练习 W/E/R 移动/旋转/缩放
5. 练习 10 分钟就熟练了

---

### 2. Content Browser 使用（15分钟）

#### 2.1 是什么
Content Browser 就是 UE 的"文件管理器"，管理所有资源。

#### 2.2 基本操作
```
双击文件夹          → 进入文件夹
右上角 ← 箭头      → 返回上一级
右键空白处          → 创建新资产
拖拽资产            → 移动/复制资产
右键资产            → 重命名/删除/复制
```

#### 2.3 重要文件夹
```
Content/
├── AutoGenerated/     ← 自动创建的资产（Input/Blueprint）
├── Ascent/            ← 导入的地图 Mesh
├── Data/              ← 点位数据 JSON
└── [其他]             ← UE 自带的资产
```

#### 速成方法
1. 打开 Content Browser（底部面板）
2. 点击各个文件夹看看里面有什么
3. 试试右键创建文件夹
4. 5 分钟就熟悉了

### 3. 放置 Actor（10分钟）

#### 3.1 方法一：从 Content Browser 拖拽

#### 3.2 方法二：Place Actors 面板

#### 3.3 方法三：创建 Blueprint

2. Blueprint Class
3. 选择父类（比如 PrefireArena）
4. 命名（比如 BP_PrefireArena）
5. 双击打开可以编辑

## 📚 需要会的知识（今天或明天学）

### 6. Blueprint 基础（20分钟）

#### 6.1 是什么
Blueprint 是 UE 的可视化编程系统，不用写代码。

#### 6.2 核心概念
| 概念 | 说明 | 类比 |
|------|------|------|
| Blueprint | 可视化脚本 | 流程图 |
| Event | 触发点 | 按钮点击 |
| Function | 执行的操作 | 函数 |
| Variable | 存储的数据 | 变量 |
| Node | 流程图的节点 | 方块 |
| Wire | 连接节点的线 | 箭头 |

#### 6.3 我们项目中的 Blueprint
| Blueprint | 作用 | 你需要做什么 |
|-----------|------|--------------|
| BP_AscGameMode | 游戏模式 | 设置 Input，引用其他 Blueprint |
| BP_Crosshair | 准星 Widget | 设计 UI 外观 |
| BP_StatsPanel | 统计面板 | 设计 UI 外观 |
| BP_EnemyTarget | 敌人目标 | 可能需要调整参数 |
| BP_PrefireArena | 训练场地 | 放到场景就行 |
| BP_TrainingManager | 训练管理器 | 放到场景就行 |
| BP_EnemySpawner | 敌人生成器 | 放到场景就行 |

#### 6.4 怎么创建 Blueprint
1. Content Browser 右键 → Blueprint Class
2. 选择父类
3. 命名（以 BP_ 开头）
4. 双击打开编辑

#### 速成方法
1. 创建一个简单的 Blueprint（比如 BP_Test）
2. 双击打开
3. 在 Event Graph 中右键，搜索 "Print String"
4. 连接到 BeginPlay
5. 保存，拖到场景，按 Play 测试
6. 你会看到屏幕上打印文字
7. 10 分钟就理解了

### 7. UMG Widget 设计（30分钟）

#### 7.1 是什么
UMG (Unreal Motion Graphics) 是 UI 设计系统，用来做准星、血条、菜单等。

#### 7.2 核心控件
| 控件 | 作用 | 用途 |
|------|------|------|
| Text | 文字 | 显示文字 |
| Image | 图片 | 显示图片/色块 |
| Button | 按钮 | 可点击 |
| Border | 边框 | 带边框的容器 |
| Canvas Panel | 画布 | 自由定位 |
| Vertical Box | 垂直排列 | 自动垂直排列 |
| Horizontal Box | 水平排列 | 自动水平排列 |

#### 7.3 我们需要的 UI

**准星 (BP_Crosshair):**
```
┌─────────────────┐
│      │          │  ← 竖线 (Image)
│ ─────┼─────     │  ← 横线 (Image)
│      │          │
│      ●          │  ← 中心点 (Image)
└─────────────────┘
```

**统计面板 (BP_StatsPanel):**
```
┌─────────────────┐
│    训练统计      │  ← 标题 (Text)
│                 │
│ 命中率: 75%     │  ← Text
│ 爆头率: 30%     │  ← Text
│ 总射击: 100     │  ← Text
│ 总命中: 75      │  ← Text
│ 最佳反应: 250ms │  ← Text
└─────────────────┘
```

#### 7.4 怎么设计
1. 双击 Widget Blueprint 打开
2. 从 Palette 面板拖控件到画布
3. 在 Details 面板修改属性（位置、大小、颜色、文字）
4. 用锚点(Anchor)控制布局

#### 速成方法
1. 创建一个 Widget Blueprint（BP_TestUI）
2. 拖一个 Text 到画布
3. 修改文字内容
4. 拖一个 Image，设置颜色为红色
5. 调整位置和大小
6. 保存，在 PlayerController 中创建并显示
7. 15 分钟就入门了

### 8. Enhanced Input 系统（15分钟）

#### 8.1 是什么
UE5 的新输入系统，替代旧的 Action/Axis Mapping。

#### 8.2 核心概念
| 概念 | 说明 | 例子 |
|------|------|------|
| Input Action (IA) | 单个输入 | "跳跃"、"射击" |
| Input Mapping Context (IMC) | 按键绑定 | "W=前进"、"Space=跳跃" |
| Trigger | 触发条件 | 按下、松开、持续按 |

#### 8.3 我们需要的 Input
| Input Action | 用途 | 绑定按键 |
|--------------|------|----------|
| IA_Move | 移动 | WASD (2D) |
| IA_Look | 看 | 鼠标 (2D) |
| IA_Walk | 慢走 | Shift (按住) |
| IA_CrouchToggle | 蹲下 | Ctrl (切换) |
| IA_Jump | 跳跃 | Space (按下) |
| IA_Fire | 射击 | 鼠标左键 (按下) |

#### 8.4 自动创建
我们的 `ue_auto_setup.py` 脚本会自动创建这些资产，你不需要手动创建。

#### 速成方法
1. 运行 `ue_auto_setup.py` 脚本
2. 在 Content Browser 看看创建了什么
3. 双击 IMC_Default 看看按键绑定
4. 5 分钟就理解了
