## 第一步：打开项目

### 1.1 找到项目文件
```
F:\project\gitprojects\UE\valorant\ascent1\ascent1.uproject
```

### 1.2 双击打开
- 双击 `ascent1.uproject` 文件
- 如果弹出"选择 Unreal Engine 版本"，选择 **UE 5.3**
- 点击 **打开**

### 1.3 等待加载
- 第一次打开会编译 C++ 代码，可能需要 **2-5 分钟**
- 看到右下角进度条走完就是加载好了
- 如果弹出"编译成功"提示，点 **确定**

### ⚠️ 常见问题
- **问题：** 弹出"项目需要重新编译"
- **解决：** 点"是"，等编译完

- **问题：** 编辑器打不开，报错
- **解决：** 检查是否有杀毒软件拦截，或者检查 UE 5.3 是否安装完整

## 第二步：认识 UE 编辑器界面

打开编辑器后，你会看到这样的界面：

```
┌─────────────────────────────────────────────────────────┐
│  菜单栏: File  Edit  Window  Tools  Build  ...          │
├─────────────────────────────────────────────────────────┤
│  工具栏: [保存] [编译] [Play] [暂停] [停止] ...          │
├──────────────┬──────────────────────────────────────────┤
│              │                                          │
│  放置面板     │          3D 视口（主窗口）                 │
│  (Outliner)  │          你看到的场景                     │
│              │                                          │
├──────────────┴──────────────────────────────────────────┤
│                                                         │
│  底部面板: Content Browser（资源浏览器）                  │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 重要面板说明

| 面板 | 在哪里 | 作用 |
|------|--------|------|
| **Content Browser** | 底部 | 浏览和管理所有资源（类似文件管理器） |
| **Outliner** | 左上角 | 显示场景中所有物体（类似图层列表） |
| **Details** | 右侧 | 显示选中物体的属性 |
| **World Settings** | 右侧（需要点开） | 设置关卡的 GameMode 等 |
| **Output Log** | 底部（需要切换） | 显示日志和 Python 控制台 |

### 如何打开缺失的面板
如果看不到某个面板：
- **Content Browser**: 菜单栏 → **Window** → **Content Browser**
- **Outliner**: 菜单栏 → **Window** → **Outliner**
- **Details**: 菜单栏 → **Window** → **Details**
- **Output Log**: 菜单栏 → **Window** → **Developer Tools** → **Output Log**

## 第三步：运行自动设置脚本

这一步会自动创建 Input 资产和 Blueprint。

### 3.1 打开 Python 控制台
1. 菜单栏 → **Window** → **Developer Tools** → **Output Log**
2. 在 Output Log 面板的 **底部**，有一个下拉框，默认显示 `Cmd`
3. **点击下拉框**，选择 **Python**
4. 现在你可以输入 Python 代码了

### 3.2 运行脚本
1. 用记事本打开这个文件：
   ```
   F:\project\gitprojects\UE\valorant\ascent1\Tools\ue_auto_setup.py
   ```
2. **Ctrl+A** 全选，**Ctrl+C** 复制全部内容
3. 回到 UE 编辑器，点击 Python 控制台的输入框
4. **Ctrl+V** 粘贴
5. 按 **Enter** 运行

### 3.3 等待执行
- 控制台会输出很多日志
- 看到 `AUTO SETUP COMPLETE!` 就是成功了
- 如果有红色错误，截图发给我

### 3.4 验证创建的资产
在 Content Browser 中：
1. 导航到 `Content` 文件夹
2. 应该能看到一个新文件夹叫 `AutoGenerated`
3. 点进去，应该有：
   - `IA_Move`, `IA_Look`, `IA_Walk`, `IA_CrouchToggle`, `IA_Jump`, `IA_Fire`（Input Actions）
   - `IMC_Default`（Input Mapping Context）
   - `BP_AscGameMode`, `BP_Crosshair`, `BP_StatsPanel`, `BP_EnemyTarget`（Blueprints）

## 第四步：导入 FBX 地图

这一步把 Blender 导出的地图导入 UE。

### 4.1 运行导入脚本
1. 同样在 Python 控制台（Window → Developer Tools → Output Log → 切换为 Python）
2. 用记事本打开：
   ```
   F:\project\gitprojects\UE\valorant\ascent1\Tools\ue_import_fbx.py
   ```
3. **Ctrl+A** 全选，**Ctrl+C** 复制
4. 粘贴到 Python 控制台，按 **Enter**

### 4.2 等待导入
- 导入 7356 个 Mesh 需要 **5-15 分钟**
- 控制台会显示进度
- **不要关闭编辑器！** 耐心等待

### 4.3 验证导入结果
导入完成后：
1. 在 Content Browser 中，导航到 `Content` → `Ascent` 文件夹
2. 应该看到很多 Mesh 资产
3. 数量应该有 **几千个**

### ⚠️ 常见问题
- **问题：** 内存不足报错
- **解决：** 关闭其他程序，重启编辑器再试

- **问题：** 导入时间太长
- **解决：** 正常！7000+个 Mesh 需要时间，耐心等

## 第五步：打开 Ascent 关卡

### 5.1 找到关卡文件
1. 在 Content Browser 中，导航到 `Content` 文件夹

## 第六步：放置游戏 Actor

这一步把 PrefireArena、TrainingManager、EnemySpawner 放到场景中。

### 6.1 放置 PrefireArena

#### 方法一：从 Content Browser 拖拽
1. 在 Content Browser 中，导航到 `Content` → `AutoGenerated`
2. 找到 `BP_PrefireArena`（如果没找到，用方法二）
3. **拖拽** 到 3D 视口中
4. 松开鼠标，Actor 就放到场景里了

#### 方法二：用 Place Actor 面板
1. 菜单栏 → **Window** → **Place Actors**（放置面板）
2. 在搜索框输入 `PrefireArena`
3. 如果搜不到，说明 Blueprint 还没创建，需要用 C++ 类：
   - 在 Content Browser 右键 → **Blueprint Class**
   - 搜索 `PrefireArena`，选择它
   - 命名为 `BP_PrefireArena`
   - 双击打开，不做任何修改，直接关闭

### 6.2 放置 TrainingManager
同样方式：
1. 拖拽 `BP_TrainingManager` 到场景
2. 或者创建 Blueprint 子类 `BP_TrainingManager`（父类选 `TrainingManager`）

### 6.3 放置 EnemySpawner
同样方式：
1. 拖拽 `BP_EnemySpawner` 到场景
2. 或者创建 Blueprint 子类 `BP_EnemySpawner`（父类选 `EnemySpawner`）

### 6.4 调整位置（可选）
- 选中 Actor，用 **W** 键切换到移动模式
- 拖拽箭头移动位置
- 或者在右侧 Details 面板中手动输入坐标

### 💡 小贴士
- 如果找不到 C++ 类，在 Content Browser 点右上角的 **Settings** 按钮
- 勾选 **Show Plugin Content** 和 **Show Engine Content**
- 然后再搜索

## 第七步：设置默认 GameMode

这一步告诉 UE 使用我们自定义的游戏模式。

### 7.1 打开 World Settings
1. 菜单栏 → **Window** → **World Settings**（世界设置）
2. 会在右侧 Details 面板旁边多出一个标签页

### 7.2 设置 GameMode
1. 在 World Settings 中，找到 **Game Mode** 部分
2. 找到 **GameMode Override** 或 **Default GameMode**
3. 点击下拉框，选择 **BP_AscGameMode**
4. 如果找不到 BP_AscGameMode：
   - 点击下拉框旁边的 **Browse** 按钮
   - 导航到 `Content` → `AutoGenerated`
   - 选择 `BP_AscGameMode`

### 7.3 保存
- 按 **Ctrl+S** 保存关卡

## 第八步：设计准星 UI

这一步设计射击准星的外观。

### 8.1 打开 BP_Crosshair
1. 在 Content Browser 中，导航到 `Content` → `AutoGenerated`
2. 双击 `BP_Crosshair` 打开 Widget 编辑器

### 8.2 Widget 编辑器界面
你会看到：
- **中间**：画布（白色矩形区域）
- **左侧面板**：Palette（控件列表）
- **右侧面板**：Details（属性编辑）
- **底部**：Hierarchy（控件层级）

### 8.3 设计准星
最简单的准星设计：

#### 添加一个十字准星
1. 在 Palette 面板中，搜索 `Image`
2. 拖拽到画布上
3. 在 Details 面板中设置：
   - **Position X**: 190（水平居中附近）
   - **Position Y**: 195（垂直居中附近）
   - **Size X**: 20（宽度）
   - **Size Y**: 2（高度，很细的横线）
   - **Color**: 白色或绿色

4. 再拖一个 Image 到画布上：
   - **Position X**: 195（垂直居中附近）
   - **Position Y**: 190
   - **Size X**: 2（宽度，很细的竖线）
   - **Size Y**: 20

#### 添加中心点
1. 再拖一个 Image 到画布上：
   - **Position X**: 195
   - **Position Y**: 195
   - **Size X**: 4
   - **Size Y**: 4
   - **Color**: 红色（这样更容易瞄准）

### 8.4 保存
- 按 **Ctrl+S** 保存

### 💡 更高级的准星
你也可以用：
- **Border** 控件来做带边框的准星
- **Canvas Panel** 来更精确地定位
- **Animation** 来做准星扩散动画

## 第九步：设计统计面板 UI

这一步显示命中率、反应时间等数据。

### 9.1 打开 BP_StatsPanel
1. 在 Content Browser 中，双击 `BP_StatsPanel`

### 9.2 设计面板
#### 添加标题
1. 从 Palette 拖一个 `Text` 到画布
2. 在 Details 中设置：
   - **Text**: `训练统计`
   - **Font Size**: 24
   - **Color**: 白色

#### 添加数据文本
再拖 5 个 `Text` 控件，分别设置：

| Text 控件 | Text 属性 | 用途 |
|-----------|-----------|------|
| Text1 | `命中率: --%` | 显示命中率 |
| Text2 | `爆头率: --%` | 显示爆头率 |
| Text3 | `总射击: 0` | 显示总射击数 |
| Text4 | `总命中: 0` | 显示命中数 |
| Text5 | `最佳反应: --ms` | 显示最佳反应时间 |

#### 布局建议
```
┌─────────────────────┐
│     训练统计         │  ← 标题
│                     │
│ 命中率: --%         │
│ 爆头率: --%         │
│ 总射击: 0           │
│ 总命中: 0           │
│ 最佳反应: --ms      │
```

## 第十步：测试运行

### 10.1 进入游戏模式
1. 确保你还在 Ascent 关卡中
2. 点击工具栏上的 **Play** 按钮（绿色三角形 ▶）
3. 或者按 **Alt+P**

### 10.2 测试操作
进入游戏后：

| 操作 | 按键 | 说明 |
|------|------|------|
| 移动 | W A S D | 前后左右 |
| 跳跃 | Space | 空格键 |
| 蹲下 | Ctrl | 左 Ctrl 切换蹲 |
| 慢走 | Shift | 左 Shift 按住慢走 |
| 射击 | 鼠标左键 | 开火 |
| 瞄准 | 移动鼠标 | 转向 |
| 退出游戏 | ESC | 退出 Play 模式 |

### 10.3 验证功能
测试以下内容：
- [ ] 移动是否正常（WASD）
- [ ] 鼠标是否控制视角
- [ ] 左键是否能射击
- [ ] 准星是否显示
- [ ] 跳跃/蹲下是否工作

### 10.4 退出 Play 模式
- 按 **ESC** 键
- 或者点工具栏的 **Stop** 按钮（方形 ■）

### ⚠️ 常见问题
- **问题：** 点 Play 后没有反应
- **解决：** 确保关卡已保存（Ctrl+S），GameMode 已设置

- **问题：** 不能移动，什么都没反应
- **解决：** Input 资产可能没创建成功，重新运行 `ue_auto_setup.py`

- **问题：** 准星不显示
- **解决：** 检查 BP_Crosshair 是否正确创建，PlayerController 是否引用了它

## 第十一步：SpotEditor 使用

SpotEditor 是一个网页工具，用来编辑训练点位。

### 11.1 启动 SpotEditor
1. 打开命令行（Win+R，输入 cmd，回车）
2. 输入以下命令：
   ```
   cd /d F:\project\gitprojects\UE\valorant\ascent1\Tools\SpotEditor
   npm run dev
   ```
3. 看到类似这样的输出就是成功了：
   ```
   VITE vX.X.X  ready in XXX ms
   ➜  Local:   http://localhost:3000/
   ```

### 11.2 打开浏览器
1. 打开浏览器（Chrome/Edge/Firefox）
2. 访问：`http://localhost:3000`
3. 应该看到 SpotEditor 界面

### 11.3 使用 SpotEditor
- 左侧是地图预览
- 右侧是点位列表
- 可以添加/删除/移动点位
- 编辑完成后点 **Export** 导出 JSON

### 11.4 导出数据
1. 在 SpotEditor 中编辑好点位
2. 点 **Export** 按钮
3. 保存为 `prefire_spots.json`
4. 覆盖到：
   ```
   F:\project\gitprojects\UE\valorant\ascent1\Content\Data\prefire_spots.json
   ```

## 常见问题

### Q: 编辑器太卡怎么办？
A: 
1. 关闭其他程序
2. 在编辑器中：**Settings** → **Engine Scalability Settings** → 选择 **Low**
3. 关闭实时渲染：按 **Alt+S** 切换到线框模式

### Q: 怎么保存？
A: 
- 保存关卡：**Ctrl+S**
- 保存资产：在 Content Browser 中右键 → **Save**
- 保存所有：**Ctrl+Shift+S**

### Q: 怎么撤销？
A: 
- **Ctrl+Z** 撤销
- **Ctrl+Y** 重做

### Q: 我的资产在哪里？
A: 
- 所有自动生成的资产在 `Content/AutoGenerated/`
- 导入的地图在 `Content/Ascent/`
- 点位数据在 `Content/Data/`

### Q: 怎么重新运行脚本？
A: 
- 脚本是幂等的，重复运行不会出错
- 已存在的资产会被跳过

### Q: Python 控制台在哪里？
A: 
- **Window** → **Developer Tools** → **Output Log**
- 底部下拉框切换为 **Python**
