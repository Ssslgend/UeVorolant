# 亚海悬城对枪训练

运行交付目录中的 `ascent1.exe`。地图、材质、音效和训练点位随程序附带，无需打开 Unreal 编辑器。

复制到其他位置时，请复制整个 `Windows` 文件夹，保留程序旁的 `Engine`、`ascent1` 目录。

## 训练

- 自由探索：按原地图路线走图，熟悉掩体和高低差。
- 预瞄练习：从掩体后探身，停稳、对准爆头高度，再开枪。
- 架枪练习：守住角度，敌人会随机延时探身。
- 背闪练习：看到闪光提示后转身避闪，再回头击杀敌人。朝向、距离和遮挡影响致盲。
- 防守波次：连续应对 5 波进攻，全部击杀后完成本轮。
- 实战对枪：沿地图路线寻找 3 个目标；保留当前生命值，敌人可能蹲姿并移动。

可选择 A 区、中路、B 区和具体点位。简单、普通、困难的敌人反应预算分别为 650、400、250 毫秒。爆头可一枪击杀，躯干需要多枪；移动射击有散布。

头部每枪伤害 160，躯干、手臂和颈部 40，腿部 34；敌人生命值为 100。墙体和掩体会挡住子弹。

打中身体或腿部时，敌人短促闪白，命中处出现小火花，准星周围出现白色标记，并显示伤害和剩余生命。头部命中使用金色火花、独立的金属脆响与金色命中标记；爆头击杀后，画面下方出现带红色爆头标记的击杀徽记。普通击杀使用青色徽记。这些反馈只在子弹实际命中后触发，空枪或墙体遮挡不会显示命中确认。

对枪模式被敌人打中时，画面边缘短暂变红并显示剩余生命。每次有效命中都会增加“命中”，敌人生命耗尽才增加“击杀”；例如身体第一枪造成 40 伤害、剩余 60 生命，此时击杀仍为 0。身体第三枪或头部一枪可完成击杀。

敌人为红色身体、黄色头部，并有颈部连接；头部直径为 18 厘米，显示大小与爆头判定一致。站姿和蹲姿保留对应的爆头高度。

本轮结束后仍可走动查看站位，射击和计分停止；按 R 重练，按 N 切换下一点位。

敌人抢先开枪时，本轮立即失败，画面中央会显示重练提示，并清除敌人。此时按 R 开始新一轮，再射击；结束后的开枪不会增加命中。

## 操作

| 按键 | 功能 |
|---|---|
| WASD | 移动 |
| 移动鼠标 | 控制视角；上移抬头，下移低头 |
| Shift | 静步 |
| Ctrl | 切换蹲姿 |
| 空格 | 跳跃 |
| 左键 | 射击 |
| R | 重练本轮 |
| N | 下一点位 |
| Esc | 暂停、打开菜单或回到训练 |
| F5 | 记录当前玩家位置 |
| F6 | 记录当前敌人位置 |
| F7 | 将两处位置保存为个人点位 |

记录个人点位时，先用自由探索走到玩家站位按 F5，再走到目标站位按 F6、F7。回到训练菜单后可在点位列表选择。个人点位适合自由探索和预瞄；预置点位另有经校验的探身路线。

采集的是脚下实际地面高度；请落地站稳后记录，跳跃中不能采集。

## 设置和记录

设置立即生效并保存。DPI 用于显示 cm/360，不会修改鼠标硬件 DPI。默认灵敏度 0.4、800 DPI 对应约 40.82 cm/360。

导出会生成 `settings_export.json`，软件会显示完整路径。将要导入的设置命名为 `settings_import.json` 放到设置页显示的目录，再点击导入。格式或数值错误时保留原设置。

本机保存设置、个人点位和最多 100 条训练记录。记录页显示枪数、命中、爆头、首次反应、急停射击比例、瞄准偏差和完成情况。

## 地图

本程序使用从原始 Blender 文件删减生成的战斗地图。保留真实地面、墙体、箱体、入口、高低差和原有高度参照；删去远景、装饰和无关模型。未在墙上增加额外的彩色爆头线。

保留中路坡道挡墙、庭院箱体、A/B 包点箱体、船屋基座、内外墙和必要护栏。跨越战斗区边界的大墙体按实际范围保留，避免因中心落在边界外而整面删除。
